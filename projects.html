Speech Emotion Recognition

Compared Random Forest and SVM classifiers on 6-class emotion recognition using CREMA-D (7,442 audio samples), measuring balanced accuracy and macro-AUC to judge performance under class imbalance.

SVM reached a macro-AUC of 0.82 vs. 0.80 for Random Forest. Tuned Random Forest efficiency with constrained depth, feature subsampling, and SelectFromModel, and analyzed scalability trade-offs for deployment.

DigiPen · Machine Learning 2 · Team project

Hybrid Movie Recommender System

Co-developed a hybrid recommender on MovieLens 100K (943 users, 1,682 movies, ~94–97% sparsity) combining cluster-based KNN collaborative filtering, SVD matrix factorization, and a knowledge-based recommender.

K-means++ segmentation brought KNN RMSE down to 1.112 and tuned SVD reached 1.067. The hybrid weights collaborative and knowledge-based scores dynamically, with fallback logic so every user gets recommendations.

  • Python
  • NumPy
  • SVD
  • K-means++
  • KNN
